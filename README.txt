## Free hosting
The site can be published with GitHub Pages at no hosting cost.

1. Create/sign in to a GitHub account.
2. Create a new repository (for example: `speak-jesus`).
3. Upload `index.html` and the `assets` folder.
4. Open the repository's Settings → Pages.
5. Select "Deploy from a branch", choose the `main` branch and `/ (root)`.
6. GitHub will provide the public page link.

The ticket button currently uses the event website shown on the supplied flyer: https://www.mymusicspeaks.org/
